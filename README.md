# CopyShot - AI Ad Copy Generator

**From Drew Is: Tools to UpLevel your message**

This Streamlit app helps you generate high-converting ad copy using GPT-4 and proven frameworks.

## 🔧 How to Run Locally

1. Make sure Python 3.9+ is installed.
2. Install Streamlit and OpenAI:
   ```
   pip install streamlit openai
   ```
3. Run the app:
   ```
   streamlit run copyshot.py
   ```
4. Enter your OpenAI API key when prompted.

## 🧠 Features
- Supports frameworks: AIDA, PAS, Story, Hook + CTA
- Multiple tone options (gritty, luxury, bold, etc.)
- Outputs 3 ad variations per run
- Copy-paste ready
